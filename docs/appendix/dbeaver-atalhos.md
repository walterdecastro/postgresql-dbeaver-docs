# Atalhos Úteis do DBeaver

## Execução de queries

| Ação                              | Windows / Linux          | macOS                   |
|-----------------------------------|--------------------------|-------------------------|
| Executar query atual              | `Ctrl + Enter`           | `Cmd + Enter`           |
| Executar script inteiro           | `Alt + X`                | `Option + X`            |
| Executar do cursor até o final    | `Ctrl + Shift + X`       | `Cmd + Shift + X`       |
| Explicar plano de execução        | `Ctrl + Shift + E`       | `Cmd + Shift + E`       |

## Edição e formatação

| Ação                              | Windows / Linux          | macOS                   |
|-----------------------------------|--------------------------|-------------------------|
| Formatar SQL                      | `Ctrl + Shift + F`       | `Cmd + Shift + F`       |
| Comentar / descomentar            | `Ctrl + /`               | `Cmd + /`               |
| Auto-complete                     | `Ctrl + Espaço`          | `Ctrl + Espaço`         |
| Duplicar linha                    | `Ctrl + D`               | `Cmd + D`               |

## Navegação

| Ação                              | Windows / Linux          | macOS                   |
|-----------------------------------|--------------------------|-------------------------|
| Novo editor SQL                   | `Ctrl + ]`               | `Cmd + ]`               |
| Toggle Database Navigator         | `Ctrl + Shift + D`       | `Cmd + Shift + D`       |
| Fechar aba atual                  | `Ctrl + W`               | `Cmd + W`               |
| Trocar entre abas                 | `Ctrl + Tab`             | `Cmd + Option + →`      |

## Outros

| Ação                              | Windows / Linux          | macOS                   |
|-----------------------------------|--------------------------|-------------------------|
| Salvar script                     | `Ctrl + S`               | `Cmd + S`               |
| Buscar no script                  | `Ctrl + F`               | `Cmd + F`               |
| Preferências                      | `Ctrl + Shift + P`       | `Cmd + ,`               |
