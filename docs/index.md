# PostgreSQL com DBeaver

Bem-vindo ao tutorial completo de **PostgreSQL** com foco total no **DBeaver**.

Este material foi criado para ser um guia prático e progressivo: do zero até conceitos avançados de banco de dados, sempre utilizando o DBeaver como ferramenta principal.

## O que você vai aprender

- Instalar e configurar o PostgreSQL corretamente
- Dominar o DBeaver (conexão, interface, scripts, diagrama ER)
- SQL do básico ao avançado (DDL, DML, Joins, Subqueries, Window Functions, CTEs...)
- Criar Triggers, Functions e Procedures com PL/pgSQL
- Analisar e otimizar queries com `EXPLAIN ANALYZE`
- Entender Transações, isolamento e MVCC

## Como usar este material

Use o menu lateral para navegar. Os capítulos estão organizados em ordem de aprendizado:

1. **Preparação do Ambiente** — instalação e configuração
2. **DBeaver** — a ferramenta que usaremos em todo o restante do tutorial
3. **Nível Básico** — fundamentos do SQL
4. **Nível Intermediário** — consultas mais poderosas
5. **Nível Avançado** — recursos profissionais do PostgreSQL

Recomendação: siga a ordem dos capítulos e pratique cada exemplo no DBeaver.
